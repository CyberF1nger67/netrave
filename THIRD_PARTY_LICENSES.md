# Third-party notices

netrave is distributed under the GNU General Public License v3.0 only (see
[LICENSE](LICENSE)). This file lists third-party components that are shipped
inside the release archive or inside the compiled binary, with their copyright
notices and license texts.

Components used only to build or test netrave (for example Vite, Vitest,
Playwright, TypeScript, Tailwind, lightningcss, caniuse-lite) are not
distributed and are not listed here.

How each list was produced:

- Go: the modules of `go.mod` that are actually linked into the Linux binary
  (`go list -deps ./...`). Each row was checked against the `LICENSE` file in
  the module cache (`go mod download -json <module>`).
- Frontend: the npm packages whose modules are rendered into the bundle
  (`internal/web/static/assets/*.js`), taken from the Rollup module graph of
  the production build and checked against `frontend/package-lock.json`.
